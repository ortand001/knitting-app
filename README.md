# 🧶 Top-Down Seamless Knitting Pattern Generator

A browser-based tool for generating customised top-down seamless knitting patterns for sweaters, cardigans, and vests.


## ✨ Features

- **Top-down seamless construction** — no seaming required
- **Three garment types** — Pullover, Cardigan, Vest
- **Three construction styles** — Raglan, Drop Shoulder, Set-in Sleeve
- **7 sizes** — XS to 3XL with accurate measurements
- **8 yarn weights** — Lace to Super Bulky (including Aran)
- **Customisable ease** — Fitted to Oversized
- **German short rows** — for better neck/shoulder shaping
- **Accurate yarn calculations** — based on real pattern data
- **PDF download** — save your pattern for offline use
- **Standalone yarn calculator** — estimate yarn without generating a full pattern

## 🧵 Pattern Features

### Construction Methods
- **Raglan** — Seamless yoke with diagonal shaping lines
- **Drop Shoulder** — Simple construction, relaxed fit
- **Set-in Sleeve** — Traditional tailored look

### Included Techniques
- German short rows for back neck shaping
- M1L/M1R increases for invisible shaping
- SSK/K2tog decreases that mirror each other
- YO/K2tog buttonholes for cardigans
- 2:3 pick-up ratio for armholes and bands
